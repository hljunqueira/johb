# Salada Soul - Project Overview

## What is Salada Soul?
A food delivery platform for an organic salad restaurant with:
- **Public Menu**: Browse products, customize "Monte sua Salada", add to cart
- **Checkout**: Order with delivery or pickup, PIX payment
- **Order Tracking**: Real-time status updates
- **Admin Panel**: Manage orders, products, customers, reports

## Tech Stack
- **Frontend**: React + Tailwind CSS + Shadcn UI
- **Backend**: FastAPI (Python)
- **Database**: MongoDB
- **Auth**: JWT + Google OAuth
- **Deployment**: Vercel (frontend) + Railway (backend)
